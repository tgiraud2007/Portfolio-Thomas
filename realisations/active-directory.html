Un domaine Active Directory de A à Z

Mise en place d'un domaine Active Directory sous Windows Server 2022, dans un réseau virtuel VirtualBox.

  • Windows Server 2022
  • AD DS
  • GPO
  • DNS
  • DHCP
  • NTFS
  • hMailServer

Contexte

TP de 1re année de BTS SIO, réalisé seul, dans un réseau virtuel VirtualBox.

Ce que j'ai fait

  • Installation du rôle AD DS et promotion du serveur en contrôleur de domaine.
  • Création d'utilisateurs et de groupes.
  • GPO : verrouillage de session, connexion automatique des lecteurs réseau selon le service, blocage du panneau de configuration pour les utilisateurs standard.
  • DHCP avec plage d'exclusion et réservations ; DNS avec zones de recherche directe et inverse.
  • Partages de dossiers avec droits NTFS.
  • Messagerie interne avec hMailServer.

Vérifications

Jonction au domaine d'un poste Windows 10 et d'un poste Debian. Application des GPO contrôlée sur les postes avec gpupdate /force puis gpresult /r.
